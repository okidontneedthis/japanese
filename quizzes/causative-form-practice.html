Causative Form — "make/let someone do ~"

Translate each sentence into Japanese using the causative form. Type your attempt, then reveal the answer.

u-verbs (Group 1): change u→a, add せる — 買う→買わせる, 読む→読ませる, 待つ→待たせる, 話す→話させる
ru-verbs (Group 2): drop る, add させる — 食べる→食べさせる, 見る→見させる
irregular: する→させる, 来る→来させる
particle: the person is marked with に if the verb already has an を object (母は私に野菜を食べさせます), or with を if the verb has no other object (先生は学生を待たせました)
